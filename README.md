KenKen Creator & Candidate Solution Generator - CSCI5801-43582-Fall.A2

Our group plans to implement the KenKen Puzzle Creator and the KenKen Candidate Solution Generator using the specified Data Interchange Format. The Creator will be a graphical user interface that allows unsolved/unfilled puzzles to be created with valid regions each with their target value and operator. The Creator will transmit the puzzle to be solved to the Generator in the XML interchange format. The Generator will calculate all valid cell value combinations for each region.
